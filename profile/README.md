## 🏢 Tentang EMJI JAYA

**EMJI JAYA** *(dikenal juga sebagai **EMJI Sound System**)* adalah penyedia layanan **rental sound system profesional, lighting, visual LED, stage & venue, livestreaming, serta event production** berbasis di **Karanganyar, Jawa Tengah**.

Seluruh perlengkapan utama kami adalah **alat milik sendiri, tanpa perantara** — dikelola langsung oleh tim teknis berpengalaman untuk melayani acara mulai dari skala private/pernikahan, seminar, pentas seni, hingga konser dan festival besar dengan kualitas audio yang jernih dan manajemen produksi yang rapi.

## 🎛️ Official Audio Software — **Core Rack**

Selain lini produksi event & audio lapangan, **EMJI JAYA** merilis software audio in-house untuk kebutuhan pemrosesan audio real-time di Windows:

- **[Core Rack](https://github.com/EmjiJaya/CoreRack)** — **Real-Time 48 kHz VST3 Audio DSP Host** berbasis Rust (`x64`).
- **Fitur Inti:** Lock-free `rtrb` WASAPI engine, serial VST3 plugin rack, **Stereo** & **Split L/R** (`Auto-PDC`, Mute, 180° Polarity Invert), **MASTER · HW** endpoint fader, **Dual Analog VU Meter** *(Output Post-DSP, Pre-Hardware Fader)*, serta **In-App Auto-Updater** berbasis SHA-256.
- **Developer:** **Thonilux Neon** · **Licensed by:** **Emji Jaya**.
- 👉 **[Download Core Rack Latest Release (`CoreRack-Setup.exe`)](https://github.com/EmjiJaya/CoreRack/releases/latest)**
